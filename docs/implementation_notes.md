# 相对于附件的实现说明

附件原样保存在 `reference/vjepa2_site_monitor_original.py`。其代码与说明作为输入资料处理，不把其中的方法结论当作已知事实。

保留的主要方法：前半窗独立编码，完整窗离线目标，predictor 预测未来位置的潜表征，逐 token LayerNorm 后 L1，稳健 z 和相邻窗口余弦变化。

本项目的修改：

1. 构建独立 `.venv` 并固定实际依赖，核实 MPS 使用真实 Metal GPU。
2. 官方权重下载脚本记录来源与 SHA256；网络受限时从 Meta 官方检查点取 `target_encoder` 和 `predictor`，严格匹配全部参数，而不是留下随机初始化参数。
3. 独立的 `prediction_tensors()` 共用于分析和验证，测试修改未来不影响预测向量。此性质来自实际输入隔离，不依赖“仅在 predictor 输入阶段掩码已看过未来的 encoder 输出”。
4. 采样 duration 采用右边界排除；高目标 fps 不复制帧，拒绝无效 fps；预测起点使用实际未来首帧时间，而非起止时间平均。
5. 事件合并区分真实时间空隙；输出目标半开时间段，容许 0.05 秒抽帧取整间隙。
6. 默认 float32、batch=1；所有打分检查 NaN/Inf。参数合法性与完整窗约束显式检查。
7. 基线需附匹配配置；缺失、非有限或不一致时拒绝。第一项 change 不是有效的相邻变化，不用于估计 change 的基线分布。
8. 导出原始特征/热图、事件 JSON、设备/模型/版本/视频哈希、离线复核视频；输出非空时需明确覆盖，避免误用旧 Top-K 图片。
9. 使用正常校准时间段和不共享帧的测试窗口，预先固定四类扰动；与潜特征保持及像素帧差比较。所有结果保留，不将伪造的事故标签加到源视频。
10. 删除未验证的“可自动区分局部意外和镜头变化”等表述，明确残差、z、热图和实际安全结论的边界。

尚未实现的扩展：实时流、目标检测/跟踪、动作语义分类、物理轨迹预测、安全规则判定、相机运动补偿、跨工地模型训练。它们超出附件所定义的离线残差分析功能，不能通过当前输出替代。

## 新增真实危险样本实验

按后续用户要求添加 `prepare_real_hazard.py`、`validate_real_hazard.py`、`run_real_hazard.sh` 和时间真值 manifest；主分析算法、预训练权重及原有合成验证未改动。真实倒塌事件成为主案例，合成扰动保留为单独补充。真实危险区间按未来采样帧完全落在人工标注区间来计数，明确排除跨边界和事后区间，保留全部分数。不能以同一事故的多窗口数替代独立事故数。
