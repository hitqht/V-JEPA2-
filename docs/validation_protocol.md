# 验证方案（在运行模型前定义）

目标：检验冻结 V-JEPA 2 的未来半窗预测残差是否对可控的可见变化敏感。不是施工事故识别基准。

- 原始数据：KEmel49 的挖掘机装车视频，约 17.7 秒，CC BY-SA 4.0。
- 统一输入：8 fps、16 帧窗口、256×256、pad、float32；不训练、不按测试结果改阈值或挑选扰动。
- 校准：原视频 [0,8) 秒，窗口步长 1 秒。测试：从 8 秒起的互不重叠 2 秒窗口，禁止跨校准边界共享帧。
- 正类由确定性编辑产生，仅更改每个测试窗口的后 8 帧：中间 50%×50% 灰色遮挡、整幅增亮、冻结在最后一帧上下文、未来帧逆序。分别代表遮挡、光照干扰、时间停止、顺序扰动；均不能称为真实事故。
- 对照：同一窗口未编辑版本，未来与过去最后 tubelet 的潜特征 L1（persistence），像素帧差。
- 评分：V-JEPA predictor 仅接收过去半窗独立编码；真实目标由完整窗口离线编码。报告逐类 AUROC、配对分数增量/胜率、固定 z≥3 下检出率及正常误报率。AUROC 使用所有正负两两比较，平分计 0.5。
- 排除未来泄漏：固定上下文，修改未来，预测向量须相同；目标向量应变化。目标是非因果教师表征，故残差解释为掩码潜表征一致性，不能视作物理预测的概率。
- 报告全部扰动结果，包括低于随机水平的结果。少量、同一视频且有配对依赖，不作总体准确率推断，不作显著性或跨工地泛化声明。
- 视频接缝/摄像头扰动可能产生高分；热图为 patch 残差的时间平均和相对显示，不是目标检测、分割或事故定位真值。

## 图像核对后的实现修正（v2）

初次实验图像核对发现：曝光变换施加在已补边的模型输入上，连预处理的均值色边框也被增亮。这不符合相机曝光变化发生在原始画面内的定义。v2 将曝光变换限制在原始画面对应区域，保持补边不变；其他扰动、数据划分、阈值和评分均不变。该修正基于视觉发现的实现问题，而不是调参优化指标。初次实验全部数据保留在 `reports/validation_v1_padding_exposure/`，最终报告使用重新运行的 v2 数据。该视频在 256×256 模型输入中的有效区域为 y=[56,200)、x=[0,256)。
